Le studio

Construire des systèmes qu’on peut comprendre.

Je construis JARVIS: une intelligence privée pensée pour relier le travail numérique, les connaissances et les systèmes physiques.

Partir du vrai problème.

Je commence par regarder ce qui fait perdre du temps: une demande oubliée entre deux outils, un document impossible à trouver ou des appareils qui ne se parlent pas.

Je construis ensuite une petite solution, je la teste dans le réel et je l’améliore seulement quand elle fonctionne.

01 // CLARTÉ

Montrer ce qui est réel.

Les prototypes, expériences et éléments en construction sont identifiés comme tels. Aucune statistique inventée, aucun faux client.

02 // CONTRÔLE

Garder l’humain dans la boucle.

Les systèmes sensibles demandent une approbation, conservent un mode manuel et enregistrent leurs actions.

03 // INDÉPENDANCE

Éviter les cages fermées.

Nous privilégions les standards, les APIs et le contrôle local afin que votre système puisse évoluer sans tout recommencer.

JARVIS et l’Ambulance Lab.

JARVIS est le cœur du projet. L’Ambulance Lab est l’endroit où je vérifie que l’énergie, le réseau, les capteurs et l’automatisation peuvent réellement fonctionner ensemble.

Aujourd’hui, je développe les premières démonstrations pour le travail de bureau et les documents. Les premiers projets pilotes viendront seulement après les validations techniques.

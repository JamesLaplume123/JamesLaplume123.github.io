---
title: Comprendre Home Assistant sans jargon
category: Home Assistant
status: Guide
---

Home Assistant est une plateforme locale qui permet de relier des appareils de marques différentes dans une seule interface.

Au lieu d'avoir une application pour les lumières, une autre pour les caméras, une autre pour le climat et une autre pour les capteurs, Home Assistant devient le point de coordination.

Une bonne installation commence petit:

- quelques appareils importants
- un dashboard lisible
- des automatisations simples
- des sauvegardes
- une documentation claire

Le but n'est pas d'automatiser toute la maison d'un coup. Le but est de créer des routines fiables qui gardent toujours un contrôle manuel.
